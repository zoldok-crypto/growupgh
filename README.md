# growupgh.com

Статический сайт GrowUp Greenhouses (Czyste Pole sp. z o.o.). Хостинг OVH, почта Google Workspace.

- `main` → автоматически заливается на https://growupgh.com/
- `preview` → автоматически заливается на https://growupgh.com/preview/ (noindex)
- Страницы каталога генерируются: `python3 tools/build_site.py` (данные моделей внутри скрипта)
- Исходник каталога: `2027_greenhouses.pdf`, картинки в `img/cat/2027/`
