# growupgh.com

Статический сайт GrowUp Greenhouses (Czyste Pole sp. z o.o.). Хостинг OVH (FTP, папка `www`), почта Google Workspace.

- Рабочая ветка `main`. Заливка на хостинг вручную (WinSCP) из полного архива сайта.
- Страницы каталога генерируются: `python3 tools/build_site.py` (данные моделей внутри скрипта).
- Исходник каталога: `2027_greenhouses.pdf`, картинки в `img/cat/2027/`.
